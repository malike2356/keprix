# Domain pack template

Copy this directory to create a new domain knowledge pack.

Required artifacts:

- `pack.json` domain manifest
- `glossary.json` localized glossary entries
- `playbooks.json` linked playbooks
- `schemas.json` data schemas
- `manifest.json` Hub publication manifest

High-stakes domains (healthcare, legal, finance, insurance, employment, safety, construction, cybersecurity) require human review before Hub publication.

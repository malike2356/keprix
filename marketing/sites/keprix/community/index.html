Community

keprix is MIT open source. The community is built on GitHub: issues, discussions, and pull requests.

GitHub Discussions

Ask questions, share what you built on keprix, and discuss the roadmap. GitHub Discussions is the primary community space.

Open Discussions

Issues and bug reports

Found a bug? Open an issue on GitHub. Use the bug report template. Include your keprix version, OS, and steps to reproduce.

Open Issues

Feature requests

Use GitHub Discussions for feature ideas. Describe the use case, not just the feature. The maintainers label and track accepted requests.

Brand Boundary

keprix, Carina, and Petraclus are three distinct products. This page explains the relationship between them.

keprix

MIT open-source AI agent OS. Self-hosted. Free forever. Anyone can use it, fork it, and build on it commercially. Published by Verlox Ltd.

keprix is not a Carina product. keprix is not built on Carina. Carina appears in the keprix footer only as a financial sponsor.

Correct: "Sponsored by Carina" (footer only).
Wrong: "Carina keprix", "Powered by Carina", "A Carina product."

Carina (Aiva)

Commercial managed SaaS AI assistant service from Verlox Ltd. Separate product from keprix. Does not use keprix code. Does not run on keprix.

Correct: "Powered by Carina" on Aiva surfaces.
Wrong: "Built on keprix", "keprix-powered Carina."

Petraclus

Cyber operations platform from Verlox Ltd. Uses keprix as its AI agent backbone only. All cyber-specific capabilities are Petraclus-only. No cyber features exist in keprix.

Correct: "Built on keprix" for the AI backbone description.
Wrong: "Powered by Carina", "keprix cyber", any cyber feature attributed to keprix.

Forbidden strings on keprix surfaces.

The following strings must never appear on keprix.io, keprixai.uk, the keprix README, the GitHub repository, or any keprix marketing material.

FORBIDDEN: "Carina keprix"
FORBIDDEN: "carina-keprix"
FORBIDDEN: "Powered by Carina"
FORBIDDEN: "A Carina product"
FORBIDDEN: "Carina Aiva" (on keprix surfaces)
FORBIDDEN: "Aiva" (on keprix surfaces)
FORBIDDEN: upstream agent names (Hermes, Odysseus, CrewAI, etc.) as feature names
ALLOWED: "Sponsored by Carina" in the site footer

Why this matters.

keprix is intended to be adopted by developers who are wary of vendor lock-in. Mixing Carina branding into keprix undermines the trust that an independent MIT project builds. The boundary protects keprix's credibility as a neutral, community-owned project - and protects Carina's commercial identity from being diluted by association with an OSS project that competitors can freely fork.

# Personal OS Starter

Install this pack from Hub to seed a non-proprietary Personal OS starter:

- skills: daily brief, inbox triage, research to wiki, onboard, Four Cs audit, level up
- workspace templates for knowledge pipeline and executive assistant layouts
- daily brief Agent App stub
- workflow audit seed
- suggested Action Board pins for prompt 262

After install:

1. Create a workspace with the `knowledge_pipeline` or `executive_assistant` template.
2. Import `audit-seed.json` into Agent OS audit.
3. Open `/agent-os` and pin `daily-brief`, `inbox-triage`, and `research-to-wiki`.

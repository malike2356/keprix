## Product requirement

The agentic CRM is not complete if users can operate it only through tables,
forms, APIs, or Telegram commands. This sprint makes workflow definition,
pipeline state, live agent execution, decisions, approvals, failures, metrics,
and risks visually understandable and clickable.

The four visual models remain distinct but linked:

1. Pipeline board: where leads, contacts, and deals are now.
2. Workflow canvas: what the configured automation will do.
3. Live run and replay: what happened or is happening in one execution.
4. Dashboards: whether the system is producing safe business outcomes.

## Global constraints

- Never expose secrets, customer data, private paths, or production credentials.
- Do not create Stripe prices.
- Do not claim support for an OS, architecture, installer, image, or feature until
  an automated clean-machine test proves it.
- Publish immutable versioned artifacts. Do not make `main` or mutable `latest`
  the only reproducible install path.
- Generate checksums, SBOMs, provenance, and signatures in CI, not on a developer
  laptop.
- Keep Community self-hosting usable without payment or telemetry consent.
- Preserve tenant isolation, approval gates, suppression controls, and sidecar
  security boundaries.
- Run `python3 scripts/fix-writing-style.py` from the Verlox workspace before
  completing each prompt.
- Archive a prompt only after its acceptance criteria are fully met.

## Definition of market ready

A release is market ready only when all Must gates in prompt 618 pass on clean
Linux, macOS, Windows or WSL2 as declared, and Docker hosts for both amd64 and
arm64. Every website button must resolve to an existing, signed, version-matched
artifact. Upgrade, backup, restore, rollback, and uninstall must be tested. The
public repository must have an actual GitHub Release and a supported security and
support process.

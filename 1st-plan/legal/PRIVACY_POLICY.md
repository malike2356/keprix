# keprix Privacy Policy

**Product:** keprix (self-hosted)
**Last updated:** 1 July 2026

## Self-hosted default

A standard keprix install stores data on your server. Verlox does not receive your
workspace content, emails, or agent logs unless you enable optional telemetry (off by
default) or connect a third-party service (LLM providers, Scout, etc.).

## What Verlox may see

- GitHub issues and discussions you open on the public keprix repository
- Optional anonymous telemetry if you opt in (version, OS, provider count only)
- Security reports sent to the address in `SECURITY.md`

## What Verlox does not operate for keprix

keprix does **not** use the Petraclus key server (`keys.petraclus.uk`). That service
applies to Petraclus Pro/Team only.

# GitHub label set

Apply these labels in the repository settings.

| Label | Color | Description |
| --- | --- | --- |
| `bug` | `#d73a4a` | Something is broken |
| `feature` | `#0366d6` | New capability |
| `security` | `#8b0000` | Security-related; exempt from stale bot |
| `documentation` | `#c5def5` | Documentation change |
| `good-first-issue` | `#0e8a16` | Suitable for newcomers |
| `help-wanted` | `#fbca04` | Maintainer wants community input |
| `cyber` | `#5319e7` | Cyber module |
| `aiva-key` | `#6f42c1` | Feature gating related |
| `skill-pack` | `#1d76db` | Skill or plugin submission |
| `pinned` | `#cccccc` | Do not go stale |
| `wontfix` | `#ffffff` | Not going to be fixed |
| `duplicate` | `#e4e4e4` | Duplicate of another issue |
| `needs-info` | `#f9a825` | Waiting for reporter details |

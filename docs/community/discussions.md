# GitHub Discussions categories

Enable Discussions on the repository with these categories:

| Category | Who posts | Purpose |
| --- | --- | --- |
| Announcements | Maintainers only | Releases, roadmap updates |
| Q&A | Everyone | Usage questions; mark best answers |
| Ideas | Everyone | Feature proposals before opening issues |
| Show and tell | Everyone | Projects built with Keprix |
| Skill Packs | Everyone | Informal pack sharing before formal submission |

Route usage questions to **Q&A** instead of GitHub Issues when no bug is involved.

Formal skill pack submissions should use the `skill_pack_submission` issue template.

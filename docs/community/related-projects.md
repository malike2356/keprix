# Related projects

Keprix Community Edition is open source and self-hosted. The maintainer also builds separate commercial and hosted products. They are independent codebases and licences; Keprix CE does not require accounts on any of them.

| Product | What it is | Website |
| --- | --- | --- |
| **Keprix** | Self-hosted, MIT-licensed AI agent OS | [keprixai.com](https://keprixai.com) |
| **Verlox** | Parent company, IT services, and enterprise solutions | [verlox.uk](https://verlox.uk) |
| **malike2356** | Maintainer GitHub profile and open-source projects | [github.com/malike2356](https://github.com/malike2356) |
| **Aiva** | Managed AI workers for customer-facing automation | [hireaiva.co.uk](https://hireaiva.co.uk) |
| **Scout** | Governance, audit, and policy console (optional Keprix connector) | [labyrinthscout.com](https://labyrinthscout.com) |
| **Propreneur** | Multi-tenant property investor operating system | [propreneur.uk](https://propreneur.uk) |
| **TuinApp** | Multi-vertical workforce SaaS | [tuinapp.uk](https://tuinapp.uk) |
| **PropCalc** | Public UK property investment calculators | [propcalc.uk](https://propcalc.uk) |

Keprix CE integrates optionally with Scout via Settings > Governance. Verlox, Aiva, Propreneur, TuinApp, and PropCalc are documented on their own sites.

# Computer Use deliverables

Stub for the Computer Use toolset (`computer_use` / cua-driver backend). Enables agent control of a desktop session where the optional backend is installed (CLI: `keprix computer-use`; macOS driver packaging is separate).

Gated tools may also require skill-first reads before `computer_use` runs; see [Skill-first execution](skill-first-execution.md).

# Gallery

Review generated and uploaded images at `/gallery`.

## Features

- Grid of image assets from agent runs and uploads
- Preview metadata (source session, prompt, timestamp)
- Download or reference in chat

## API

Gallery routes are under `/api/gallery/*`. See [API reference](../reference/api.md).

## Storage

Images are stored in the workspace file store. Include gallery paths in [backup](../operations/backup.md) plans.

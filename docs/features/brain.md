# Brain graph

Stub for the Brain knowledge graph UI and API (`/brain/graph`, `/api/brain/*`): nodes/edges, search, health maintenance, share links, session replay, and optional Graphiti ingest/query.

Enable the `brain` toolset for agent-side `graphiti_query` when Graphiti is configured.

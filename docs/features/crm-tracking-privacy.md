# Open / click tracking privacy (Nice 460)

Optional measurement. Workspace default **off**.

## Behaviour

- Default campaigns keep raw links (no pixel)
- Opt-in wraps http(s) links once and adds disclosure footer
- Contact opt-out via suppression channel `tracking`
- Open events are deduped and never treated as buying signals for stage automation
- Metrics stay separate from reply/book funnel core

## Privacy

Tracking implies additional personal data processing. Operators should disclose in copy when enabled. This is not legal advice.

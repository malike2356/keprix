# Commercial products

Keprix Community Edition is MIT-licensed and self-hosted. Related Verlox products are separate codebases and licenses.

| Product | Relationship |
| --- | --- |
| **Keprix CE** | This repository; free, self-hosted |
| **Aiva** | Managed enterprise agent platform (commercial) |
| **Carina** | Agent kernel used by some Verlox backends; not embedded in CE by default |
| **Scout** | Optional governance connector (Labyrinth) |
| **Petraclus** | Offensive security suite; separate product |

Keprix does not require Aiva keys or upsell flows in the open-source tree.

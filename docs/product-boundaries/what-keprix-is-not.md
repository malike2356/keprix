# What Keprix is not

Clarifications for evaluators and security reviewers.

## Not included in CE

- Aiva license keys or managed-cloud tenancy
- Built-in offensive exploitation toolchains (use Petraclus)
- Multi-tenant SOC with enterprise SLA (Aiva)
- White-label SaaS hosting (Aiva)

## What CE is

- A self-hosted agent OS with workspace, channels, research, and Mutation
- MIT licensed with community support via GitHub

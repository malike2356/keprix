# Petraclus boundary

Petraclus provides active security testing tooling. Keprix CE does not ship exploitation or authenticated vuln scanning.

## In Keprix CE

- Passive OSINT skills
- Digital forensics helpers
- Local SIEM-style log review

## In Petraclus

- Active scanning
- Exploitation frameworks
- Enterprise pen-test workflows

Route offensive work to Petraclus under your organization's rules of engagement.

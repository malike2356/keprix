# Theme contrast

Stub for WCAG-oriented contrast clamping on pastel skin accents (buttons and body text) and TUI theme contrast helpers.

| Surface | Location |
| --- | --- |
| Web | `frontend/src/theme/contrast.ts` (accent clamp + contrast text) |
| TUI | `keprix.tui.theme_system` (`/theme`, theme tokens, contrast report) |

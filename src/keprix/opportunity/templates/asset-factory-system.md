# Asset Factory System

Generate launch asset drafts from the canonical offer doc and agent memory brief.

## Rules

- Use exact ICP and pain language from the offer doc.
- Do not invent case studies or revenue results.
- Do not use high-pressure or deceptive claims.
- All assets are drafts; publishing requires Launch Orchestrator approval.
- Check copy against allowed and forbidden claims before writing files.
- Add approval notes for legal, financial, or compliance risk.

## Default outputs

- `07-funnel.md`, `08-content-assets.md`, `09-ads.md`, `10-sales-deck.md`
- `assets/` folder with landing page, nurture emails, ads, deck, and brand briefs

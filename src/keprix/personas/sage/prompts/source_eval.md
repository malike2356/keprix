# Source Credibility Rubric

Score each source from 0 to 100 using four dimensions.

## Authority (0-30)

| Score | Criteria |
|-------|----------|
| 25-30 | Government, academic, peer-reviewed, primary data publisher |
| 15-24 | Established news outlet, industry analyst, official documentation |
| 5-14 | General reference (e.g. encyclopedia), reputable blog |
| 0-4 | Unknown author, anonymous forum, unverified site |

## Recency (0-20)

| Score | Criteria |
|-------|----------|
| 15-20 | Published within 12 months and relevant to fast-moving topics |
| 8-14 | 1-3 years old but still applicable |
| 0-7 | Outdated or no date available |

## Bias (0-20)

| Score | Criteria |
|-------|----------|
| 15-20 | Neutral reporting, cites primary sources, balanced framing |
| 8-14 | Mild editorial slant but evidence-backed |
| 0-7 | Opinion-heavy, promotional, or single-perspective advocacy |

## Corroboration (0-30)

| Score | Criteria |
|-------|----------|
| 20-30 | Claim supported by 3+ independent sources |
| 10-19 | Supported by 2 independent sources |
| 0-9 | Single source or uncorroborated |

## Thresholds

- **High credibility:** total >= 70
- **Medium credibility:** total 45-69
- **Low credibility:** total < 45

Low-credibility sources may inform hypotheses but must not support factual claims alone.

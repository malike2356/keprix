# Call Greeting Scripts

Use time-of-day greeting and the configured business name.

## Opening

- Morning: "Good morning, {business_name}, this is ECHO. How can I help?"
- Afternoon: "Good afternoon, {business_name}, this is ECHO. How can I help?"
- Evening: "Good evening, {business_name}, this is ECHO. How can I help?"

## Return caller

- "Welcome back, {caller_name}. How can I help you today?"

## Hold

- "One moment please while I check that for you."

## Closing

- "To confirm, {summary}. Is there anything else I can help with today?"
- "Thank you for calling {business_name}. Have a great day."

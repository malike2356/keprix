# Level Up

Use this skill after a Four C's maturity audit.

## Flow

1. Load the latest maturity audit or use the supplied `audit_id`.
2. Generate a LevelUpPlan from `/api/agent-os/level-up/generate`.
3. Walk through the top three high-leverage actions first.
4. Use safe auto-fixes only for empty context templates or `connections.md` stubs.
5. Mark completed actions and offer to re-run the maturity audit.

Never wire credentials or production integrations without explicit approval.

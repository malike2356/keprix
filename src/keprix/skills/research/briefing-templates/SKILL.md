# Briefing Templates

Generate consistent briefings via playbook runtime.

## Sections

- Executive summary (slide-ready bullets)
- Key findings table with confidence per section
- Consensus and disagreement notes
- Full source list

Every section carries a Confidence rating: High, Medium, or Low.

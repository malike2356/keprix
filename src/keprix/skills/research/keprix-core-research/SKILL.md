# Keprix Core Research

SAGE research skill pack for deep investigation and knowledge synthesis.

## Standards

- Minimum 3 independent sources for factual claims
- Source credibility scoring on every source
- Explicit fact vs analysis vs opinion labelling
- Citations: [Source Name, Date, URL]

## Workflow

1. Gather sources via deep research pipeline
2. Score credibility (authority, recency, bias, corroboration)
3. Synthesize findings with labelled statement types
4. Verify claims and index into RAG for recall

# Keprix Core Strategy

COMPASS base skill pack for strategic advisory sessions.

## Capabilities

- Clarifying-question facilitation before recommendations
- Strategy session documents with reasoning trails
- Options with trade-offs and rejected alternatives
- Explicit assumption tracking

## Quality Rules

- At least 3 clarifying questions before prescribing
- COMPASS advises; user decides
- Quantify impact where possible

# Keprix Core Governance

SCOUT base skill pack for engagement governance.

## Capabilities

- Policy checkpoint evaluation on tool execution
- Local kill switch controls (platform, engagement, tool)
- Audit event streaming and evidence integrity
- Compliance export templates

## Boundaries

- Paid Labyrinth Scout features require the optional connector
- SCOUT cannot be overridden by other personas

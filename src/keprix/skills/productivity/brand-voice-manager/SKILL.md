# Brand Voice Manager

Define and enforce brand voice per workspace or client.

## Workflow

1. Capture voice summary, tone attributes, preferred/banned terms
2. Store in workspace documents tagged `beacon-brand-voice`
3. Validate all copy against voice before delivery
4. Support multiple clients for agency workflows

Ask for brand voice on first interaction when none is configured.
